Gemini isn't connected in this single-file version. This demo gives you a study prompt to use; secure live AI requires a server endpoint so your API key isn't exposed in public code.

How to enable real Gemini

  1. Create a Gemini API key in Google AI Studio.
  2. Keep it as a private server environment variable, never in this HTML file or GitHub.
  3. Add a server endpoint (for example on Vercel) that calls Gemini.
  4. Point the tutor and Mistake Lab to that endpoint.

The rest of this demo works without an AI key.
